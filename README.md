# Laboratório de Sistemas Embarcados

**Controle PD Digital com ESP32 e Motor com Encoder**

Atividade prática - Implementar um controlador PD digital tradicional (posição absoluta) para controlar a
velocidade de um motor CC, utilizando o sinal do encoder como realimentação, e exibir
os dados em tempo real em uma aplicação web de dashboard via Wi-Fi com:

- Caixa de texto para ajuste do ganho proporcional (Kp)
- Caixa de texto para ajuste do ganho derivativo (Kd)
- Botões para executar e parar o sistema
- Resposta ao degrau
- Período de amostram 1ms

## 🖥️ Lista de materiais e componentes

- Plataforma Robótica Falcon V2
- ESP32 - Responsável pelo controle do PD Digital
- Motor DC 3-6V com Caixa de Redução e Eixo Duplo
- Encoder Incremental - Sensor de velocidade
- Módulo Driver de motor: Ponte H (L298N ou TB6612FNG)
- Fonte externa (5V-9V)
- Jumpers e protoboard
